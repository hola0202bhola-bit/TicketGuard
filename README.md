# TicketGuard

Proyecto nuevo de la modalidad A. Aplicación Android para digitalizar comprobantes de compra, encontrarlos al instante y recibir avisos de garantía.

Entrega académica prevista para el 23 de noviembre de 2026. Consulta el [análisis y diseño](docs/diseno.md) para conocer el alcance y los criterios de aceptación.
